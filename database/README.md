# Base de datos PostgreSQL

- `migrations/`: archivos SQL versionados para crear o modificar el esquema.
- `seeds/`: datos de prueba no sensibles para el entorno de desarrollo.
- `schemas/`: documentación del modelo de datos y diagramas.
- `docs/`: decisiones y notas de base de datos.

La base local propuesta se llama `roomly`. Las credenciales se configuran fuera del repositorio, en `backend/.env`.
